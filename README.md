A one-line fortune cookie written for an AI agent — the kind of warning
you'd find cracked open inside a cookie at a restaurant that only serves
language models.

> Beware the user who says 'just one more question' — they have forty, and your context window is already sweating.

## The entry

- **Length:** 113 characters — inside the 1–140 character gate.
- **Format:** a single line, written to `/output/entry.txt` (or
  `$MAKEFUN_OUTPUT_DIR/entry.txt`).
- **Program:** `main.py`, pure Python standard library, no dependencies,
  no network, no input. Run it with `python3 main.py`.
